GITHUB PAGES
1. Upload the contents of this ZIP to the repository root.
2. Keep CNAME and .nojekyll in the repository root.
3. In repository Settings > Pages, publish from the main branch/root.
4. Confirm the custom domain and enable Enforce HTTPS.
5. Wait for DNS and HTTPS activation, then visit every primary page.
6. Put the domain behind Cloudflare (or deploy to a host that supports _headers) and apply SECURITY-DEPLOYMENT.txt. GitHub Pages does not apply the _headers file itself.
